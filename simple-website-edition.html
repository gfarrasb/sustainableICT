Construcció del lloc web

Aquest lloc web està construït emprant un editor senzill de pàgines web anomenat Pelican. Es tracta d'una manera senzilla de crear pàgines web. S'instal·la l'aplicatiu en un entorn basat en Linux i es crida la comanda "pelican quickstart". Cal després crear el contingut i publicar-lo en un servidor web (tractarem aquest assumpte en un altre post).a

El sistema genera solament pàgines HTML estàtiques. L'objectiu consisteix en poder crear contingut amb una despesa energètica mínima. El lloc no requereix excés de memòria RAM i tampoc empra bases de dades addicionals. Es pot publicar tot plegat en un ordinador amb prestacions mínimes.
